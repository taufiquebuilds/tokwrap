# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work, not the person. Harassment of any kind isn't tolerated.

To report a problem, contact the maintainer, [@taufiquebuilds](https://github.com/taufiquebuilds). For matters that should stay private, open an issue asking for a private contact, without including any details, and you will get one.
